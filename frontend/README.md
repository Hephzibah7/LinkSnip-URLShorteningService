# LinkSnip

A full-stack URL shortening and link management platform built with React,
TypeScript, Node.js, Express, PostgreSQL, and Prisma.

## Overview

LinkSnip provides URL shortening, custom aliases, password-protected links,
expiration rules, bulk URL creation, click analytics, QR code generation,
tags, folders, and a documented REST API.
